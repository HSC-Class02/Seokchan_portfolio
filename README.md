## GitHub Pages 활성화 가이드

1. 저장소(Repository) 상단의 **Settings** 탭으로 이동합니다.
2. 좌측 메뉴에서 **Pages**를 클릭합니다.
3. Build and deployment 속 **Source**에서 **Deploy from a branch**를 선택합니다.
4. **Branch**를 `main` (또는 `master`), 폴더를 `/ (root)`로 설정하고 **Save**합니다.
5. 배포가 끝나면 Pages에 표시된 실제 주소를 확인합니다.

### 3단계: 파일 저장(Commit)하기
1. 화면 우측 상단(또는 맨 아래)에 있는 초록색 **`Commit changes...`** 버튼을 누릅니다.
2. 작은 팝업창이 뜨면 내용을 확인하고 파란색 **`Commit changes`** 버튼을 한 번 더 누릅니다.

---

### 4단계: 웹 화면(GitHub Pages) 배포 활성화하기
`README.md`가 저장되면 레파지토리 메인 화면에 방금 작성한 표와 내용이 멋지게 나타납니다. 이제 웹사이트 주소로 작동하게끔 설정해 줍니다.

1. 레파지토리 상단 메뉴 중 **`Settings`** (톱니바퀴 아이콘)를 클릭합니다[cite: 4].
2. 왼쪽 사이드바 메뉴에서 **`Pages`**를 클릭합니다.
3. **Build and deployment** 항목 아래의 **Source**를 클릭해 **`Deploy from a branch`**로 변경합니다.
4. 바로 아래 **Branch** 설정 칸을 `main` / `/ (root)`로 맞추고 **`Save`**를 누릅니다[cite: 4].
